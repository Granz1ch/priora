# 📱 СИМ-Рулетка v2 — чатовый Telegram-бот (ShapitoGram API)

Игровой бот в стиле casinobot/teslabot: **всё управляется текстом прямо в чате** (группе или личке),
без единой кнопки. Прокрутка SIM-номеров с индивидуальной оценкой, 6 игр на рубли, PvP-дуэли,
кланы с казной, титулы и модерация, викторины, промокоды, подкрутка для админов,
пополнение Telegram Stars.

Работает через **ShapitoGram** (`https://shapitogram.xyz/bot<TOKEN>/<METHOD>`) — совместимый
с Telegram Bot API сервер; используются только методы, проверенные вживую.

## Запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=... API_BASE=https://shapitogram.xyz python bot.py
```

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен бота (обязательно) |
| `ADMIN_IDS` | — | необязательно: дополнительные владельцы через запятую. Основные владельцы прописаны **в коде**: `simbot/config.py` → `OWNER_IDS` |
| `API_BASE` | `https://shapitogram.xyz` | базовый URL Bot API |
| `DB_PATH` | `simbot.sqlite3` | файл SQLite (схема мигрирует автоматически) |
| `BANNER_PATH` | `assets/banner.jpg` | баннер для `/start` в личке |
| `LOG_LEVEL` / `POLL_TIMEOUT` | `INFO` / `25` | логи, long-polling |

**Важно для групп.** Чтобы бот видел обычные слова («краш 500»), у него должен быть выключен
privacy mode (`@BotFather → /setprivacy → Disable`) **или** бот должен быть администратором чата.
Добавить бота в группу может **любой пользователь** — он сразу работает. Администрация ведёт только
чёрный список: `чат запретить [id]` (бот выходит и больше туда не добавляется), `чат разрешить [id]`, `чаты`.

| `KEEPALIVE_URL` | `$RENDER_EXTERNAL_URL` | публичный URL для самопинга `/health` раз в 5 мин (чтобы Render Free не засыпал) |

Порт HTTP-эндпоинта `/health` берётся из `SERVER_PORT` (bot-hosting) или `PORT` (Render/Heroku).

**Хостинг bot-hosting.net:** entry `bot.py`, start `pip install -q -r requirements.txt && exec python bot.py`.

**Хостинг Render** (`render.yaml` в корне — Blueprint):
1. Залить проект в репозиторий GitHub/GitLab (корень репозитория = корень проекта).
2. Render Dashboard → *New → Blueprint* → выбрать репозиторий → ввести `BOT_TOKEN` → *Apply*.
   Либо вручную: *New → Web Service*, Runtime **Python 3**, Build `pip install -r requirements.txt`,
   Start `python bot.py`, Health Check Path `/health`, переменные `BOT_TOKEN`, `API_BASE`.
3. Остановить бота на другом хостинге — два экземпляра с одним токеном конфликтуют (409).
4. Free-инстанс: файловая система не сохраняется (база обнуляется при деплое/рестарте) и сервис засыпает
   без трафика — самопинг включается автоматически через `RENDER_EXTERNAL_URL`.
   Для реальной игры нужен платный инстанс (Starter) + Disk `/var/data` и `DB_PATH=/var/data/simbot.sqlite3`.

`Dockerfile` — для любого Docker-хостинга (Render `runtime: docker`, Fly.io, VPS): том на `/var/data`.

## Команды игрока (слово в чате или `/команда`)

|---|---|

| `инвентарь [стр]` · `номер #ID` · `передать #ID @ник` (или ответом) · `продать #ID да` · `продать все да` · `продать все обычные да` | инвентарь номеров (каждый со своим `#ID`), подарок, продажа боту (по одному или всё сразу; без `да` — превью) |
| `продать #ID 5000` · `продать #ID 5000 @ник` · `купить #ID` · `рынок` · `лоты` · `снять #ID` | рынок: лоты и адресные предложения, комиссия `market_fee` 5 % |
| `обмен #мой #его [доплата]` · `обмен принять` · `обмен отклонить` · `обмены` · `торговля` | обмен номер-на-номер (атомарно, с доплатой) |
| `краш 500` · `краш 500 2` (авто ×2) · `забрать` | краш |
| `мины 500 3` → `7` / `откр 7 8` · `забрать` · `отмена` | мины 5×5 (1–24 мины) |
| `слоты 100` · `кубик 100 чёт|нечет|больше|меньше|1-6` | слоты (настоящий 🎰), кубик |
| `ап 100 2` · `ап #ID` · `ап #ID эпик` | апгрейд рублей / номера |
| `дуэль 1000` · `дуэль 1000 @ник` · `принять [#ID]` · `отклонить` · `дуэли` · `дуэль отмена` | PvP-дуэли в чате |
| `баланс` · `профиль [@ник]` · `бонус` · `история` · `топ [коллекция|выигрыши|прокрутки|кланы]` · `id` | профиль |
| `промо КОД` · `пополнить 5` (только в личке, 1 ⭐ = 1 000 ₽) | промокоды, Stars |
| `клан` · `клан создать ТЕГ Название` (50 000 ₽) · `клан пригласить @ник` · `клан принять ТЕГ` · `клан вступить ТЕГ` · `клан внести 1000` · `клан снять 1000` · `клан выдать @ник 500` · `клан зам/кик/передать @ник` · `клан открыть/закрыть` · `клан название …` · `клан выйти` · `клан удалить да` · `клан топ` | кланы с казной, тег `[ТЕГ]` в топе и профиле |
| `викторина` | текущая викторина; ответ — просто словом в чат |

Суммы: `500`, `2к`, `1.5к`, `всё`. Цель команды — `@ник`, ID или ответ на сообщение игрока.

## Титулы и управление

Владелец (5) > Гл. админ (4) > Админ (3) > Гл. модер (2) > Модер (1). Титул выдаётся командой
`+модер|+глмодер|+админ|+гладмин|+владелец @ник` (или ответом), снимается `-модер …`. Выдавать и снимать
можно только титулы **ниже своего**; на владельца (`OWNER_IDS` в коде) ограничение не действует.
`титулы` — список администрации, `админка` — команды твоего титула построчно (`админка модер` — один блок).

| Титул | Команды |
|---|---|
| Модер | `варн @ник причина` (3 варна = бан) · `снять варн` · `варны` · `мут 30м|2ч|1д @ник` · `размут` · `удалить` (ответом) · `игрок @ник` |
| Гл. модер | + `бан @ник причина` · `разбан` · `снять варны` |
| Админ | + `выдать 1000 @ник` · `забрать 1000 @ник` · `обнулить` · `установить 1000` · `выдать номер @ник тесто [редкость]` · `забрать номер #ID` · `промо создать КОД сумма [активаций] [дней]` · `промо удалить` · `промо список` · `викторина 100|200|300 награда задание` · `викторина стоп` · `статистика` · **подкрутка**: `краш 500 (вин)`, `мины 500 3 (луз)`, `слоты 100 (вин)`, `кубик 100 чёт (луз)`, `ап 100 2 (вин)`, `ап #ID эпик (вин)` |
| Гл. админ | + `техработы вкл|выкл` · `раздел краш|мины|слоты|кубик|ап|дуэль|крутить|кланы|викторина|передача|пополнение|бонус|промо вкл|выкл` · `разделы` · `рассылка текст` · `настройки` · `настройка ключ значение` · `оператор цена|шансы|добавить|удалить|вкл|выкл|имя|эмодзи …` · `страна добавить kz +7 🇰🇿 Казахстан` · `страна вкл|выкл` · `чаты` · `чат запретить|разрешить [id]` |
| Владелец | + любые титулы · `рефанд ID_платежа` · `аудит` |

Викторина: задание — слово (бот перемешивает буквы: «Составь слово из букв: О З О Л Т О»), пример
(`10+2` — бот считает сам) или `вопрос | ответ`. Одна активная на чат, первый верный ответ получает
награду, таймаут 10 мин (`quiz_ttl`). Для не-админов пометки `(вин)/(луз)` просто игнорируются.

## 🔐 Панель управления (секретный URL)

Веб-панель на том же порту, что и `/health` (единственный наружный порт Render): статистика по всем
игрокам, карточка игрока со всеми известными боту данными и полный контроль над игрой. Никаких
фреймворков — только aiohttp, свои статические файлы (`simbot/web/panel/`), один `app.js` без сборки.

| Переменная | По умолчанию | Описание |
|---|---|---|
| `ADMIN_PASSWORD` | `Djdaqdj157` (в коде, `simbot/config.py`) | пароль от панели; **пусто = панель выключена** |
| `PANEL_PATH` | `priora/panel` | секретный префикс: `https://<host>/priora/panel/` |
| `PANEL_ENABLED` / `PANEL_HOURS` | `1` / `72` | выключить панель совсем · сколько живёт сессия браузера |
| `PORT` / `SERVER_PORT` | — | на этом порту живут и `/health`, и панель |

```
https://priora-j7sk.onrender.com/priora/panel/          # вход по паролю
https://priora-j7sk.onrender.com/health                  # как раньше, панель не трогает
```

**Что внутри:** обзор (KPI, GGR, держание, графики по дням и часам, лента ставок, живые сессии) ·
игроки (поиск, фильтры «киты/замутые/забаненные/с варнами», сортировки, CSV) · карточка игрока
(баланс, net, инвентарь с ценой каждого номера, леджер, ставки, дуэли, обмены, лоты, платежи,
варны, рефералы, состояние FSM, полный JSON) · экономика (выдать/списать/установить/обнулить,
выдача и изъятие номеров, переоценка, настройки, операторы и их шансы, промокоды, страны) ·
игры (стоп живой краш-игры с возвратом, возврат ставки, отмена дуэли/обмена, снятие лота) ·
кланы · чаты (бан/разбан, уход бота) · платежи (рефанд ⭐) · журнал аудита · raw-просмотр любой
таблицы с удалением строк · **консоль**, где любая админ-команда бота исполняется от имени владельца.

**Безопасность.** Пароль не хранится в куке: кука — HMAC-подписанная строка `exp.rand.sig`
(HttpOnly, SameSite=Lax, `Secure` за https) с TTL `PANEL_HOURS` (72 ч); каждый POST требует
CSRF-токен в `X-Panel-CSRF` и совпадения `Origin`; неудачные входы ограничены (8/мин на IP → 429);
панель отдаёт `X-Robots-Tag: noindex` и жёсткую CSP (`script-src 'self'`), статика — по ETag.
Все действия пишутся в тот же `audit`, что и команды из чата, и подчиняются тем же правилам бота:
титул выше 4 не выдать и не снять из панели, `is_admin` синхронизируется с титулом,
возврат живой краш-игры сначала помечает игру `done` под её `asyncio.Lock` (двойной выплаты нет).

> ⚠️ **Репозиторий публичный** — пароль по умолчанию виден в `simbot/config.py`. Замени его
> переменной `ADMIN_PASSWORD` в настройках Render (там он не светится), а путь — `PANEL_PATH`.
> Панель не умеет менять пароль и не заменяет `OWNER_IDS`; доступ к панели = полный доступ к боту.

Локально пощёлкать без токена:

```bash
python3 tests/panel_demo.py     # фейковый Bot API + демо-база, http://127.0.0.1:8098/priora/panel/
```

## Экономика и игры

* Стартовый бонус 5 000 ₽, ежедневный 500–2 500 ₽ (+10 %/день серии до +70 %), реферал 1 000 ₽
  (`/start ref_<id>`). Пополнение 1 ⭐ = 1 000 ₽ от 1 звезды; платёж идемпотентен.
* Операторы 🇷🇺: 🍺 Пивкофф +7 902 — 500 ₽ · 🍞 Тесто +7 501 — 1 500 ₽ · 🏦 Сберище +7 404 — 5 000 ₽
  (самый дорогой, лучшие шансы). Редкости ⚪🟢🔵🟣🟠🔴; **цена каждого номера индивидуальна**
  (`numbers.appraise`: ключевые цифры, зеркала, повторы, год, случайный коэффициент). У каждого номера свой ID `#XXXXXX`.
* Краш `max(1, floor(96/U)/100)`; мины `m(k)=0.96/P(k безопасных)`; слоты 777 ×25, тройка ×6, две 7 ×1.5;
  кубик ×5.5 / ×1.9; апгрейд `min(95 %, 92 %/mult)`, номера `0.9·стоимость/(база цели×1.3)`, проигрыш сжигает номер;
  дуэль best-of-3 на 🎲 в чате, комиссия 5 %, открытые истекают через 15 мин.
* Кланы: создание 50 000 ₽ (`clan_price`), до 30 участников, роли глава/зам/участник, казна
  (взносы любого участника, выдача и снятие — глава), при удалении казна возвращается главе.

## Совместимость с ShapitoGram

Работают: `sendMessage` (с `reply_to_message_id`), `editMessageText`, `deleteMessage`, `sendDice`,
`sendPhoto` (multipart/file_id), `sendInvoice` XTR, `answerPreCheckoutQuery`, `refundStarPayment`,
`getMe`, `setMyCommands/Name/Description`, `deleteWebhook`, `getUpdates`.
`leaveChat`/`banChatMember` и т.п. вызываются best-effort (ошибки игнорируются) — модерация
реализована на уровне бота (мут = игнор команд, бан = отказ в обслуживании).

```bash
python tests/sim.py             # ~40 с, бот: личка + группа, 190+ проверок
python tests/panel_sim.py       # ~10 с, панель: доступ, CSRF, чтение, все действия
node tests/panel_jsdom.mjs      # интерфейс в jsdom против tests/panel_demo.py (нужен jsdom)
```
